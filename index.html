    TXP — The Technology eXPeriment

    TXP is a lightweight technology ecosystem focused on running an independent x86-64 operating system, called mX, on modern phones and PCs without requiring root. mX provides a familiar desktop-grade environment, packaged to boot and run alongside Android using user-space emulation and virtualization techniques.

    About TXP & mX

    TXP (The X Project) is an open-minded effort to bring a full x86-64 operating system experience to modern mobile hardware. It is built around mX — a compact, bootable x86-64 OS image designed to run on phones using a combination of virtualization, lightweight emulation, and optimized user-space components. The goal is to offer a usable desktop environment (terminals, package manager, GUI apps) without modifying device firmware or requiring root access.

    How it works

    mX runs as an independent OS image that boots on top of Android through a minimal hypervisor or user-space launcher. Filesystems are shared using standard mechanisms, and display/input are forwarded through well-supported bridges. This lets users run common x86-64 software (dev tools, windowed apps, servers) on commodity phones while keeping Android intact.
